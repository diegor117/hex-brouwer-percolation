A short expository paper and a page of interactive simulations about three
classical results:

1. **The Hex theorem.** A completely filled Hex board has a winning chain for
   exactly one of the two players.
2. **Gale's proof of Brouwer's theorem.** Gale (1979) derived the Brouwer
   fixed-point theorem for the square from the Hex theorem.
3. **A crossing probability.** If each cell of an $`n \times n`$ board is black with
   probability $`p`$, the probability $`\theta_n(p)`$ of a black top-to-bottom crossing
   satisfies $`\theta_n(p) + \theta_n(1-p) = 1`$, so $`\theta_n(1/2) = 1/2`$ for every $`n`$.
The results are not new. The paper is in `paper/hex-brouwer.pdf`; the
simulations are in `index.html`.

## Paper

The source is `paper/hex-brouwer.tex`. Figures and data are generated by
`scripts/make-figures.js` from the same code the web page uses, with a fixed
random seed, and written to `paper/figures/` (TikZ) and `paper/data/` (CSV).

```
node scripts/make-figures.js --n5   # --n5 also enumerates all 2^25 boards for n = 5 (a few minutes)
cd paper && latexmk -pdf hex-brouwer.tex
```

## Simulations

No build step and no dependencies. Open `index.html` in a browser or serve the
directory (`python3 -m http.server`). The page contains a Hex board (two players, or one player against a simple computer opponent),
a step-by-step version of Gale's walk, Gale's colouring of the square for a
chosen map and ε, and a Monte Carlo simulator for θ_n(p).

To publish with GitHub Pages, enable Pages from the `main` branch, root folder.

## Tests

```
node test/logic.test.js
```

- Exhaustive enumeration of all 2^(n²) colourings for n = 2, 3, 4: every
  colouring has exactly one crossing, and exactly half have a black crossing.
- 2000 random boards with 5 ≤ n ≤ 11: the union-find crossing detection
  agrees with an independent breadth-first search, and exactly one player
  crosses.
- Gale's walk on 1000 random boards with 4 ≤ n ≤ 9: the fence graph has
  exactly four vertices of degree 1, the walk ends at a different corner,
  and the winning cells along the walk contain a crossing.
- Monte Carlo on 20 000 boards of size 11 × 11 at p = 1/2: the frequency of a
  black crossing is within 5 standard errors of 1/2.
- Rectangular 2 × 3, 3 × 4 and 4 × 5 boards, all colourings: the player with
  the shorter distance crosses in more than half of them, so the result
  θ_n(1/2) = 1/2 needs a square board.
- Gale's colouring for 3 maps, n ∈ {40, 60, 80} and ε ∈ {0.15, 0.25, 0.4}:
  the hypotheses of the lemma are checked numerically, then neither player
  has a crossing, at least one cell is uncoloured, and every uncoloured cell
  moves less than ε√2.
- The same colouring with the directions reversed (cells with large
  horizontal displacement given to Black) produces a black crossing for the
  `fold` map, so the assignment of directions in the proof is needed.
- Computer opponent: takes a win in one, blocks a loss in one, and beats a
  uniformly random player in all 40 games (n = 7 and 11, both colours).

## Status of the claims

- At least one crossing: proved in the paper, following Gale (1979).
- At most one crossing: cited to Huneke (2014), not proved in the paper.
- Hex theorem implies Brouwer's theorem for the square: proved.
- θ_n(p) + θ_n(1 − p) = 1: proved; checked exhaustively for n ≤ 5 at p = 1/2.
- p = 1/2 is the critical probability, and Cardy's formula (Smirnov 2001):
  cited as context; nothing depends on them.
